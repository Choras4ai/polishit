隐私政策

最后更新：2026年6月30日 · 生效日期：2026年6月30日

波江座（长沙）人工智能应用软件有限责任公司（以下简称"我们"）非常重视用户的个人信息与数据安全。本隐私政策说明在您使用「润石 PoliShit」软件及其官网（runshi.top）时，我们如何收集、使用、存储、共享和保护您的信息。请您在使用前仔细阅读本政策。

核心原则：本软件以"按需处理"为准则。我们不将您的文本作为模型训练数据，不主动保留不必要的文本副本；您可随时选择"自配 API 模式"，使文本不经过我们的服务器。

一、我们收集的信息

我们仅收集为实现产品功能所必需的信息：

类型具体内容用途
账户信息邮箱、手机号、验证码、密码（加密存储）、显示名称注册、登录鉴权、找回账户
设备信息设备标识（设备令牌）、操作系统类型、应用版本免登录试用、设备绑定、安全风控
交易信息订单号、积分余额、充值记录、支付回调元数据积分结算、订单查询与售后
文本内容您主动选中并提交处理的中文文本及处理结果实时完成润色 / 降AIGC，不用于训练
日志与元数据请求时间、请求标识、字数、模型名称、错误信息、IP（用于风控）故障排查、安全审计、防滥用

二、文本内容的处理方式

  1. 自配 API 模式：文本直接从您的本地设备发送至您自行配置的第三方模型服务，不经过我们的服务器，我们无法接触该文本。
  2. 润石托管（积分）模式：文本会先发送至我们的后端，由后端转发至上游模型服务（如硅基流动等 OpenAI 兼容接口）完成处理后返回。我们仅在处理过程中临时处理该文本，不将其作为训练数据，不主动长期留存正文。
  3. 软件在启动时可能检查最新版本，仅用于提示更新，不会上传您的正文内容。

三、我们如何使用信息

  • 提供并维护润色、降AIGC 等核心功能；
  • 进行账户鉴权、积分结算与订单售后；
  • 保障服务安全，识别并防范滥用、欺诈与攻击；
  • 排查故障、改进产品稳定性；
  • 履行法律法规要求的义务。

四、信息共享与第三方

  1. 上游模型服务商：托管模式下，文本会转发给第三方 AI 模型服务以完成处理。我们仅传输完成请求所必需的内容。
  2. 支付通道：充值时，订单与支付信息会与微信支付、支付宝等持牌支付机构交互，以完成交易。
  3. 除上述为实现功能所必需的情形、或法律法规要求、或获得您单独同意外，我们不会向任何第三方出售或共享您的个人信息。

五、数据存储与安全措施

  • 传输层使用 HTTPS 加密；账户密码采用单向哈希加盐存储；
  • 后端具备请求限流、熔断、成本护栏与异常审计等防护机制；
  • 仅保留实现功能所必需的账户、订单与短时元数据，敏感信息按最小化原则处理；
  • 数据主要存储于中国境内的服务器。

六、数据保留期限

账户与交易信息在您的账户存续期间保留，并在法律法规要求的期限内留存；处理过程中的正文不作长期留存；日志类元数据按滚动周期清理。注销账户后，我们将在合理期限内删除或匿名化处理您的个人信息（法律另有规定的除外）。

七、您的权利

您有权查询、更正、复制您的个人信息，并可申请删除或注销账户。如需行使上述权利，请通过文末联系方式与我们联系。

八、未成年人保护

本软件主要面向有中文写作需求的成年用户。我们不面向 14 周岁以下儿童提供服务；若您是未成年人，请在监护人指导下使用，并在监护人同意后提交信息。

九、Cookie 与本地存储

桌面客户端使用本地配置存储（如 electron-store）保存您的偏好设置与登录令牌；官网仅使用必要的本地存储维持基本浏览体验，不用于跨站追踪。

十、政策更新

我们可能适时更新本政策，更新后的版本将在本页面公布并标注生效日期。重大变更我们会以显著方式提示。
