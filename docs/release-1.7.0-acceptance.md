# 1.7.0 验收记录

日期：2026-10-22。状态：本地候选版本，公开稳定版更新地址尚未切换。

## 已实现
- 配置保护词；保护词区间采用 JS/Word 一致的 UTF-16 坐标，多次出现分别保护。
- 数字、常见单位、DOI、引用标记和论断/否定词变化提醒。此规则是保守风险检测，不证明语义等价或事实正确。
- 主进程重新计算风险，不信任渲染层 safety 字段；单条风险确认、整稿替换/完成批阅拒绝未确认风险；完整复制需明确确认。
- 批量接受保留风险建议。精确批准的备选文本及任意已批准子集可组成最终稿。
- 每批最多 8 条修订请求理由，按 ID、原片段和替换值精确校验；短文不再跳过，失败明确显示理由未生成。原文卡片同步理由状态和备选。
- 结果窗持续展示原文浮窗错误，便于区分“分析失败”“无修改”“原文不可定位”。

## 独立审查
只读审查发现并修复：DOI 后缀漏报、插入否定词漏报、新增单位漏报、已批准替代值误拦、撤销部分批准后最终稿误拦。
复核未发现新的严重绕过；审查不代表宿主实机验收。

## 发布门槛
- 全量自动测试：272 项通过、0 失败。新增 Word 插入项缺少 oldText 的回归用例及共用校验修复。安装包构建结果在执行完成后补记。
- Mac Word：选区→分析→精确下划线→悬停→单条接受→验证原文→撤销，须有真实记录。当前不得声称已通过。
- Windows Word：须独立真机覆盖 COM、滚动、多显示器 DPI、表格与修订模式。跨平台打包不等于运行验收。
- Mac 测试包使用 ad-hoc 签名，不是 Apple Developer ID 公证发行包。
- `docs/version.json` 保持已有线上稳定版；新下载上传与验收完成前，不生成指向不存在文件的自动更新链接。

## 范围
本版没有引入逐字实时分析、跨文档自动学习偏好或新聊天子系统；这些属于调研方案的后续阶段。
