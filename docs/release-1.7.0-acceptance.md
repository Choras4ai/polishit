# 1.7.0 验收记录

日期：2026-10-22。状态：本地候选版本，公开稳定版更新地址尚未切换。

## 已实现
- 配置保护词；保护词区间采用 JS/Word 一致的 UTF-16 坐标，多次出现分别保护。
- 数字、常见单位、DOI、引用标记和论断/否定词变化提醒。此规则是保守风险检测，不证明语义等价或事实正确。
- 主进程重新计算风险，不信任渲染层 safety 字段；单条风险确认、整稿替换/完成批阅拒绝未确认风险；完整复制需明确确认。
- 批量接受保留风险建议。精确批准的备选文本及任意已批准子集可组成最终稿。
- 每批最多 8 条修订请求理由，按 ID、原片段和替换值精确校验；短文不再跳过，失败明确显示理由未生成。原文卡片同步理由状态和备选。
- 结果窗持续展示原文浮窗错误，便于区分“分析失败”“无修改”“原文不可定位”。
