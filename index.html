下载前，你可能想知道

这里提供源代码吗？

这里是润石官方产品与安装包发布仓库。桌面应用源代码现为私有，不提供公开源码；GitHub 自动生成的 Source code 归档仅包含此展示站点与发布说明，不是桌面应用源码。

演示和实际软件完全一样吗？

网页展示可操作的设计预览。实际软件受安装版本、系统权限与编辑器接口影响。仅能在可靠核对原文位置与内容时直接写回；其他情况使用结果窗审阅或复制。开发测试版不会作为稳定版自动发布。

安装后怎样开始？

打开润石，按引导配置服务。在支持的编辑器中选中文字，使用浮窗或快捷键触发；macOS 默认快捷键为 ⌘⌥V，Windows 为 Ctrl+Alt+V。更多说明见润石官网。
